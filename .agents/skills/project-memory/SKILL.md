# project-memory

Use this skill when:

- continuing work in a fresh chat
- reviewing prior work
- checking project decisions
- understanding current state
- resuming after a break
- summarizing the project before coding

## Steps

1. Read `references/summary.md`.
2. Read `references/decisions.md`.
3. Read `references/open_questions.md`.
4. Summarize completed work, current status, key decisions, open questions, and the next best step.
5. Check whether the new request conflicts with previous decisions.
6. After important work, update the reference files.
