# chat-to-memory

Use this skill when you paste or reference an old chat and want only durable project memory extracted.

## Steps

1. Extract only durable information from the supplied chat.
2. Separate findings into:
   - completed work
   - decisions
   - unresolved issues
   - next steps
3. Update the project-memory reference files.
4. Avoid copying temporary discussion, repeated brainstorming, or irrelevant chatter.
5. Preserve existing important memory and merge cleanly without duplication.
